create

POST /events/2026-09/send

Operation ID: post-/events/2026-09/send_send.

Authentication: oauth2 (oauth2).

Request body

application/json

Property Type Required Description
email string No The visitor's email address. Used for associating the event data with a CRM record.
eventName string Yes The event's fully qualified name. This value (formatted as pe&#123;HubID&#125;_&#123;name&#125;) can be retrieved through the event definitions API or in HubSpot's UI.
objectId string No The ID of the record for which the event occurred (for example, contact ID or visitor ID).
occurredAt string (date-time) No The time when this event occurred. If this isn't set, the current time will be used.
properties object Yes The event properties to update. Takes the format of key-value pairs (property internal name and property value). Learn more about HubSpot's default event properties.
utk string No The visitor's usertoken. Used for associating the event data with a CRM record.
uuid string No A unique identifier for the event occurrence. Must be unique within the event type. If not provided, HubSpot will generate a random UUID. When multiple events have the same ID within a year, the first will be accepted and all others will be rejected. Can be useful for matching data between HubSpot and other external systems.
